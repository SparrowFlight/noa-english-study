# 出海英语训练台

这是为客厅电视、无线键盘和手机共同设计的大屏英语训练 App。

当前岗位化计划见 [研发市场桥梁英语12周计划.md](./研发市场桥梁英语12周计划.md)，App 内的“今天”“12周”“场景”“句库”已同步为“研发—市场桥梁型智驾产品”版本。

“今天”和“12周”页面会显示当天对应的教材、Unit、页码和配套音频/练习；详细章节索引在计划文档中。

每天只要求完成“01 今天·必做”。45分钟版是标准流程，20分钟版用于忙日，90分钟版只在时间充裕时使用。“03 场景加练”和“05 主动复习”是选做；测评每14天做一次。

## 最简单的打开方式

双击 `index.html`，适用于只看计划、场景、句库和训练计时。

双击 `启动学习助手.cmd`，浏览器会自动打开 `http://localhost:8766`。这种方式还支持麦克风录音和离线缓存，并且同一 Wi-Fi 下的 iPhone 也能访问。

启动窗口会同时显示手机访问地址。保持该窗口打开；不需要时按 `Ctrl+C` 停止。

## iPhone 访问

1. 在电脑上双击 `启动学习助手.cmd`。
2. 记录启动窗口中显示的 `iPhone: http://...` 地址。
3. iPhone 和电脑连接同一 Wi-Fi，在 Safari 打开该地址。
4. 在 Safari 分享菜单中选择“添加到主屏幕”。

Windows 防火墙第一次询问时，需要允许 Python 的专用网络访问。

## 键盘

- `Enter`：开始或下一步
- `Space`：暂停或继续计时
- `R`：显示答案
- `左/右方向键`：上一步或下一步
- `F`：全屏
- `Esc`：返回

## 能力测评

进入“06 测评”，按顺序完成：

1. 三段本地听力，完成后自动计分并显示原文。
2. 五个限时口语任务，可逐题录音、回放和下载。
3. 两组发音词句录音。
4. 90秒工作说明。
5. 下载 JSON 测试报告。

测试进度保存在当前标签页中；录音保存在当前页面内存中，关闭页面后需要重新录制。每段口语录音可在完成页单独下载。

## 数据

学习记录保存在当前浏览器的本地存储中。清理浏览器数据前，请在“设置”中导出进度。

教材扫码音频和视频仍从出版社授权平台播放。本 App 不复制或绕过这些资源。
